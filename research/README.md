implementation, tests, configuration, feature dictionaries, and selected saved

A source snapshot can contain a prepared, partially executed, failed, or completed
notebook. These states are not equivalent. Historical negative findings and errors
remain evidence; their presence does not imply that every subsequent result failed.
Read the time-stamped stage and source receipts rather than treating green presentation
or column counts as competitive progress.
