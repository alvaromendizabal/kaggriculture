## Scope
Publish manually developed Kaggriculture research into the existing public repository.
Includes research implementation, tests, feature dictionaries, saved notebook evidence,
selected summary reports, and a new employer-facing overview.

## Safety and provenance
- Core baseline and recorded engine/data contracts are preserved.
- Existing Git history, license notices, and the prior README are retained.
- Source snapshots are mapped by package and byte hashes.
- Raw source episodes, credentials, environments, and large checkpoints are excluded.
- Missing package folders and incomplete notebook execution markers remain explicit.

## Research interpretation
Rounds 21 and 22 are separate first outcome ablations of previously activated
collection-completion and maintenance-deadline families. Their state must be read
from the saved receipts: prepared code is not an executed result, and local coins
are not a Kaggle leaderboard rating. No automatic feature promotion is claimed.

## Review requirements
Review the full staged content and notebook outputs, local publication receipts,
and existing CI before merging. Publication safety checks are not a replacement for
research tests or a guarantee that all historical commits are free of secrets.
